## 9. 현재 가장 중요한 장애 이력 — 경주정보 불러오기

사용자가 실제 앱에서 확인한 장애:
- 2026-10-02(금) 제주 경주 → 실패
- 2026-10-02(금) 부산경남 경주 → 실패
- 2026-10-03(토) 제주 2R → 실패
- 지역을 바꿔도 경주정보 실패가 빈번

이 문제 때문에 다른 기능 테스트를 할 수 없었다.

### 확인된 root cause

1. 검빛 페이지의 race header에 NBSP/비정형 공백이 포함되어 기존 정규식이 날짜/경주번호를 놓칠 수 있었음.
2. 검빛 URL `type` 값을 지역별 고정값처럼 다룬 것이 잘못됨.
3. 실제 경주일 기준 type 후보를 검증해야 함.
4. 검빛 단일 소스 실패가 앱 전체 실패로 이어졌음.
5. 출전마 표도 “마번/마명/조교사/기수 포함 아무 테이블”로 잡아 잘못된 테이블을 선택할 위험이 있었음.

### 수정된 구조

- `GumvitPageParser`
  - NBSP 대응
  - 날짜 파싱
  - 경주번호 파싱
  - 지역 identity 확인
  - 경주일 요일 기준 type 후보:
    - 금요일 우선 5
    - 토요일 우선 6
    - 일요일 우선 7
    - fallback 5/6/7/1
  - `전적 + 조교사 + 기수`를 포함하는 정확한 출전마 인기도 표 선택

- `GumvitBridge.fetchResilient()`
  - 검빛 우선
  - 검빛 실패/구조변경/identity mismatch 시 KRA fallback
  - 둘 다 실패할 때만 전체 실패

## 10. KRA fallback 구조

검빛이 막히거나 HTML 구조가 깨져도 앱이 죽지 않도록 KRA 공식 페이지를 2차 데이터원으로 사용한다.

KRA 사용 목적:

1. 경주 존재/identity 확인
2. 출전마 복원
3. 말취소/출전표 변경 보완

현재 사용 구조:

- 경주 존재:
  `https://race.kra.co.kr/thisweekrace/ThisWeekWeight.do`

- 출전내역/기수별 출전:
  `https://race.kra.co.kr/chulmainfo/Riding.do?Act=02&Sub=3&meet={1|2|3}`
  - 서울 = 1
  - 제주 = 2
  - 부산경남 = 3

- 출전표 변경 / 말취소:
  `https://race.kra.co.kr/thisweekrace/ThisWeekChulmapyoChange.do`

`KraRaceParser`가:
- 날짜
- 지역
- 경주번호
- 마번
- 마명
- 기수
- 조교사

를 복원하고,
KRA 출전표변경의 취소마를 제거한다.

최종 원칙:
**검빛 성공 → 검빛 사용**
**검빛 실패 → KRA 사용**
**둘 다 실패 → 사용자 실패표시**
