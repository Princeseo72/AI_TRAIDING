## 학습식
Prediction Snapshot은 immutable, 실제결과는 race_outcomes에 분리 저장.
position별 gradient = actualHorse(feature) - predictedHorse(feature).
delta = learningRate*gradient - regularization.
newWeight = clamp(oldWeight+delta).
Global/Regional candidate를 각각 생성하며 단일 경주로 Champion 즉시 교체 금지. 최소표본/guardrail 통과 후 ACTIVE.

## Closed Loop
결과확정 → ML candidate → Regional → Horse/Jockey/Trainer Rating → Track 상태 → Error Attribution → Blend/Calibration → Drift → Next-Race Materialization.
다음 경주 buildInput은 getPreRaceContext의 runner Rating/Regional/Hist를 contextSignals로 주입한다.

## 강제학습
최종출력에서 분석을 먼저 저장한 뒤 '실제착순 직접확정·학습'.
예: 4,1,10.
서로 다른 유효출전마 3개 + 사용자 재확인 필수.
source=MANUAL_CONFIRMED_OUTCOME.
자동학습과 동일 trainFromResult/applyClosedLoopUpdate를 사용한다.
analysis_record_id UNIQUE + seen race guard로 중복학습 금지.
강제학습은 원하는 예측을 강제하는 기능이 아니라 확정 실제결과를 수동 공급하는 기능이다.

## 신뢰도
Hist=PENDING 또는 Regional sample<20이면 HIGH 금지, LOW.

## 검증
제주 2026-10-05 3R 실제 4→1→10 수동확정 시 trained sample +1, Regional +1, Rating event 생성, weight delta 저장, 다음 Context 생성, 재학습 차단.
학습 전/후 다음 경주 context feature가 달라져야 한다.
제외마 leak 0, NaN/Infinity 0.
